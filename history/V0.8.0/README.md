# 踢厄工程管理坊 TRAADuoDuo V0.8.0(20261022)

2026-10-22。Python／PySide6 桌面程式，GPL v3。依已確認的V0.8規劃實作，保留 V0.7.0 與使用者原始資料。本次交付含Google Drive同步，不包含GitHub發布、PsTOAA技能包、EXE或簽署安裝包。Windows系統匣已實作並測試條件分支，但尚未Windows實機驗收。

## 新入口與啟動

後續工作根目錄統一使用 <project-root>。本版位於 2026-09-22/x20/outputs/TRAADuoDuo/V0.8.0/；舊 Qoo 入口不作為掛載前提。

保留完整版本資料夾，不要只搬走啟動 py 檔。在本版資料夾執行：

    python3 -m pip install -r requirements.txt
    python3 TRAADuoDuo_V0.8.0.py

亦可使用 TRAADuoDuo_V0.8.0.pyw、start_macos.command 或 start_windows.bat。macOS 保留核心鎖，Windows使用原子檔案鎖；再次啟動會啟用既有視窗。QA使用獨立資料與設定。

## 本版修改

- 自動儲存改為停止輸入60秒才寫入，背景寫入不鎖住整個介面；中文組字、表格編輯器及尚未確認的對話框會延後。儲存期間的新輸入仍是未儲存草稿，不會被舊快照覆寫。
- 工程費用：預算發包工程費預算＝發包工程＋進項稅額（唯讀）；兩區管理費基數＝包工費＋自辦工費＋自購材料費＋路備材料費＋路購材料費。未完工程＝含稅發包工程費預算／契約金額＋有效工程管理費＋自辦工費＋自購材料費＋路備材料費＋路購材料費＋其他費用＋監理費＋運雜費。其他費用含空污與擴充，只加一次。
- 管理費分攤不再檢查與提撥合計相等，人工生效期輸入移除，依同階段提撥的期數連動；分攤與支用都截至所選期。找不到唯一提撥時明確提示，不猜期數。舊人工生效期保留為歷史資料。
- 管理費下方清單與編輯表移除估驗金額（稅）、實發金額、實發稅金、保留款、估驗送件日期；歷史值仍保留。計價稅金、計價日期、送審日期與備註保留，不影響發包工程頁的同名欄位。
- 表頭高度為實際文字＋3pt；契約執行欄高減3pt；管理費提撥資料列18pt，中間累計文字16pt、額外行距0.3pt、金額靠左。當日施工曆方框2pt。預算管理費顯示整數千分位，其他欄原精度規則保留。
- 金額輸入完成後自動千分位，編輯中不強制格式化而跳動游標；招標次數可手動修改，工程內須為唯一正整數。
- 事記本不顯示項次，預設依輸入／原清單順序；可上移／下移並保存、日期升降冪及關鍵字搜尋。搜尋與排序只改檢視，移位只在完整手動順序下可用；原ID與歷史項次保留。
- 工具列「匯出」提供PDF與Excel。預設目前篩選、排序與可見欄位，可選全部紀錄／全部欄位；先存檔或明示草稿。PDF是可搜尋中文文字，表頭重複、長文分頁、寬表分欄組，月曆提供月格報表。Excel日期與金額為真正型別，識別碼保留文字；不執行使用者文字公式、不嵌入外部文件／照片或來源完整路徑。
- Windows可最小化到系統匣，雙擊還原，提供顯示／儲存／結束與記憶選項；系統匣不可用時保留正常最小化。關閉仍走未儲存提示。macOS不顯示此功能。
- 「關於」依指定iOS內容規格調整：中文與英文名稱、單一來源版號日期、程式設計者Atex Lin、可點擊的使用回饋信箱atexapp.lin@gmail.com。

### 延續V0.7功能

- 文件庫增加項次、文件文號、文件日期；項次按數字升／降冪，另有文件日期排序。排序只影響檢視，不偷偷重編資料。
- 「重新編項次」僅在全部文件檢視可用，先顯示筆數與原項次→新項次對照表，確認後依目前顯示順序從 1 編起；取消不改資料，解鎖後可回復動作復原。
- 「顯示欄位」支援八欄勾選、全部顯示與恢復預設；至少保留項次或文件名稱。隱藏、欄寬、排序存本機設定，文件 ID、庫存與 PDF 註記不受重編影響。
- 大事記分為「事記本」「期限追蹤」，原事記本清單與 ID 保留；鎖定、儲存與回復分別作用於所選副分頁。
- 期限追蹤包含上方 #FFCBB3 的 5 天內到期表、下方八欄期限清單；支援新增、編輯、移除與完成篩選，上方點選可定位同筆工作。
- 未到期黃色、今日到期橘色、逾期紅色白字粗體。逾期日＝限期日隔天，當天算第 1 天；填完成日後停止警示，完成時逾期日數保留在提示中。
- 開啟、跨日、恢復前景及編輯後刷新；單純刷新不更動業務資料。發文時間可只填日期，或 YYYY-MM-DD HH:MM，不虛構午夜時間。

### 保留既有功能

- 施工曆到契約工期完成日為止顯示工期，之後保留日期及事件、不再延續數字；未設定工期不推算。
- 工程費用輸入欄為實際文字行高＋3pt；包工費以外維持對齊唯讀欄。工程管理費原合計到元、調整後預設截千元規則不變；預算區管理費整數顯示不改原值精度。
- 保證金金額顯示千分位整數，編輯與保存仍保留未改動原值的精度；招標日期範圍單行置中。
- 假期、補班、疏運同頁三表，原疏運獨立分頁移除；資料與欄寬記憶保留，窄窗上下排列並可捲動。
- 發包工程與發包以外的筆數移至累計截至右側；發包工程第二行顯示（累計計價＋累計稅金）÷ 含稅契約金額，兩位百分比，分子範圍均截至所選期。
- 文件／照片共用同庫內容去重：檔案大小＋SHA-256、候選重新校驗、OS 鎖、背景可取消、不同內容保留版本；同內容跨工程重用，不刪除舊重複檔。

## 舊資料庫與多工程

本版使用 schema 10。從下方資料庫／載入舊資料庫入口選 V0.7.0 或更早的資料庫，以唯讀預覽、另建新庫的方式匯入，不原地升級來源。舊費用存historical_v070快照，人工分攤期數保留歷史欄，新統計改用階段提撥期數。原事記本、期限追蹤與文件ID保留；更早版本缺少頁面時才補預設值。TR_FxWork使用相同入口，未對應值與原始快照保留。

工程以穩定 ID 隔離。匯入前備份目標庫，整批交易失敗回滾，不修改來源。來源如含 Docstore 庫存，匯入後先轉為來源庫檔案的連結，須勾選「庫存檔」才複製至目標 Docstore。

## 版面、欄寬與計價

- 基本資料副分頁改為「契約執行」；契約執行、工程費用、保證金的項目及輸入文字為 16pt。
- 一般表單欄預設 240，工程名稱／說明／保固備註預設 360。表格拖曳表頭邊界；表單在輸入欄右緣拖曳。日期與下拉欄亦可調整。
- 欄寬保存至本機 QSettings，跨分頁、工程及重啟保留，不寫入工程資料。「還原欄寬」只還原目前頁面。
- 施工曆星期標題列為實際文字行高加 3pt，預設七欄填滿；拖曳星期列邊界調整後記憶欄寬，星期與日期保持對齊。
- 工程計價三個分頁的累計區採 #CEFFCE 色塊、16pt 文字。管理費依計價、費別、可支用額排成同類型單行。
- 期數依整數排序：1、2、3、…、9、10、11，可切換降冪；同一期多筆保留，操作依穩定 ID，不依排序後列號。
- 原管理費合計四捨五入到元；調整後預設值仍依精確合計截千元，不先四捨五入再截千。手動歷史金額保留。
- 擴充費用不再提供隱藏按鈕，每筆後方有「-」，確認後同步移除預算／契約項目，並可復原。
- 決標顯示全形「＊」，招標內容置中；鐵路資料顯示為「鐵路疏運表」。

## AA 詳細表

提供預算表、招標表、契約表、變更表。解鎖後選目標副分頁，按「依序匯入 Excel」選 .xlsx、工作表與表頭列，預覽確認後新增獨立修訂版，不覆蓋既有資料。相同來源雜湊及工作表不重複新增。

16 欄依序為：檔別、動支單號、工程項目、工程項目中文說明、計算來源項目、計算來源項目中文說明、序號、本局材料編號、工程數量單位、數量、單價、金額、計算用比例、算式說明、規格說明、備註。

保留前導零、字母編碼、原始列序、公式（含共享公式展開）、快取值及無標題的額外欄位。父項按同一檔別／動支單號的最長既存前綴對應；最長碼預設標記單價分析層，較短末端另保留。支援修訂版、層級、展開／收合及隱藏欄位設定。

單價及金額顯示千分位與兩位小數，儲存不截掉原精度。不執行任意公式、不刷新外部連結、不重複加總父項與單價分析子項，也不自動覆寫工程費用。

## 大事記

解鎖後新增，以浮出日曆選日期；確認後返回主表輸入說明／備註，不需輸入項次。可搜尋日期／說明／備註、依日期排序或回手動順序上下移位；原ID與歷史項次不改。文字欄預設約50中文字寬，欄寬、軟折行及自動行高保留。

## 文件庫、照片庫與 Docstore

解鎖後拖曳至清單或按「加入檔案」，預設只建立連結。分類樹可新增子分類、改名與移動；可編輯顯示名稱、分類、摘要及來源連結，按名稱／拍攝日期／手動順序排列。

- 勾選「庫存檔」才複製，SHA-256 校驗成功才標示完成；失敗保持原連結。
- 新庫存放在資料庫旁 Docstore/<資料庫ID>/objects/<雜湊前綴>/<SHA-256>/<首次檔名>，相對路徑可隨資料庫資料夾搬移。原工程／項目／版本目錄繼續可讀，查重僅限同庫，不跨其他資料庫。
- 「更新庫存」內容真的改變才新增版本；相同內容重用既存檔。每筆顯示名稱、分類、註記、原連結各自保留。來源尺寸／修改時間變動時提示來源已更新，不默默覆蓋庫存。
- 取消勾選或移除清單不刪原始文件，既有庫存不自動清理；同名檔以 ID 分隔，不互相覆蓋。
- 離線／缺檔明確提示，可編輯來源重新連結。照片旋轉只影響顯示，不改原圖。
- JPEG／PNG 提供背景縮圖及大圖；拍攝日期只採 EXIF DateTimeOriginal，缺少就標示未提供。HEIC／RAW 依本機解碼能力，未支援時仍可連結、庫存或使用系統程式開啟。
- PDF 提供連續頁面、縮放／頁碼記憶、書籤與拖框重點標記。新增註記須解鎖，註記存於統一資料庫，不寫入原始 PDF。其他格式使用「開啟」交由系統程式處理。

### 完整備份／還原

文件庫／照片庫「完整備份」會先儲存目前工程，再封裝整庫、清單引用的庫存及歷史版本，產出含 SHA-256 manifest 的 ZIP。連結型原檔列為外部依賴，不假裝已備份。已移出清單的孤立庫存不自動清理，也不包含於清單引用的備份。

「還原備份」驗證後另建全新資料夾，不覆蓋目前工程；再由資料庫入口開啟其中 library.db。舊式 .db 備份僅保存資料庫；含庫存的單工程 .db 匯出會提示改用完整備份。

## 驗證與限制

本版實際Qt畫面在docs/previews/v080/、macOS原生畫面在docs/previews/v080-native/；驗收見docs/V0.8.0_validation.md。舊測試依確認的新基數、提撥期數及欄位調整，交易、隔離、原始資料保存、PDF註記與文件去重驗證仍保留。

本機使用 macOS、Python 3.14.5、PySide6 6.11.1。Qt offscreen 畫面及事件測試不等於 Windows 實機、所有螢幕 DPI 或使用者正式資料庫驗收。未執行 Excel 原生重算；未驗證所有加密／損壞 PDF 或所有 HEIC／RAW 變體。

docs/其他舊版報告、screenshots/與previews/v070/為歷史參考，不是V0.8.0驗證證據。Windows系統匣與DPI、Excel原生應用程式，以及使用者正式工程資料尚未實機驗收。Excel本身約15位有效數字限制不改變資料庫Decimal原值。
