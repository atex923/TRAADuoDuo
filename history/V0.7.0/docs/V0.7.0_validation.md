# TRAADuoDuo V0.7.0 驗收紀錄

日期：2026-10-18，Asia/Taipei。環境：macOS、Python 3.14.5、PySide6 6.11.1。資料庫 schema 9；獨立版本目錄，不覆寫 V0.6.1。

## 完成範圍

- 文件庫八欄：項次、文件名稱、文件文號、文件日期、庫存檔、分類、狀態、備註。
- 項次數字升／降冪；文件日期排序；原名稱、拍攝日期、手動順序仍保留。排序偏好與欄寬、隱藏設定存在本機 QSettings，不改業務資料。
- 全部文件檢視的重新編項次有可捲動對照表、總筆數與確認／取消；ID、來源及 Docstore 路徑不改，可透過頁面回復動作復原。分類篩選時禁止重編。
- 大事記主標籤仍在原位置，右側增加事記本／期限追蹤副標籤；原 diary 資料與 ID 不改。副分頁選擇記憶、鎖定及回復作用頁已接線。
- 期限清單八欄完整；日期用日曆選取，發文時間可選填 HH:MM。完成日期可清空回復未完成狀態。
- 逾期日為限期日隔天；當天算第 1 天。例：10/20 限期，10/21 紅色 1 天。日期、警示顏色及日數分開，不重複儲存推導值。
- 5 天內到期表含今天至 +5 日，排除逾期與已完成；#FFCBB3 區塊，同日依項次數字排序，點選按穩定 ID 定位下方紀錄。無資料顯示說明文字。
- 30 秒日期偵測與恢復前景時刷新，儲存不會停止計時器；刷新不產生 dirty、undo 或儲存。
- 新庫完整保存、工程隔離、舊庫唯讀匯入與可攜備份／還原；原庫文件補入項次，文號／文件日期留白，期限清單初始為空。

## 驗證

完整測試為 194 項：原有 177 項回歸＋17 項新驗收。啟用提供的 AA 工作簿唯讀測試，沒有略過 AA 測試；歷史 V0.4.1 程式建立的真實舊庫亦納入唯讀轉換檢查。測試日誌隨本報告附於 validation-v070/。

新增案例涵蓋到期日前／當日／隔日、跨年及閏日、完成時凍結逾期日數、5 日包含邊界、輸入驗證、純檢視不變更資料、1／2／10 數字排序、重編取消及復原、篩選防護、欄寬／隱藏／排序重開記憶、文件編輯對話框儲存重開、期限對話框取消與儲存、多工程隔離、備份還原、交易拒絕後原資料及 revision 不變、schema 8 原檔雜湊不變。

既有庫存勾選測試改依欄位鍵尋找，不再假設第 2 欄；驗證文件／照片跨頁去重及 PDF 功能仍通過。其餘舊斷言只更新 schema 9 及新增副分頁的預期。歷史程式驗收可用 TRAA_V041_TEST_SOURCE 指定來源；獨立解壓未提供來源時明確略過該項，不假裝已驗證。

macOS Cocoa 實際入口啟動及正常關閉成功；QA 使用獨立資料根目錄及原單實例鎖，不中止使用者正式程式。單實例的核心鎖／重複啟動回歸維持通過。

本版 52 個 Python／PYW 檔通過 AST 解析。V0.6.1 的 121 個 manifest 檔案及原始交付 ZIP SHA-256 全數相同，舊版未修改。
