## 需求與實作

1. 工程費用的所有金額（含管理費、擴充費用、包工費以外）顯示千分位兩位小數；MoneyField 與擴充欄分離原值／顯示值，沒有編輯就不截斷原始精度。管理費原合計到元、預設調整後截千元計算不變。
2. 預算與契約未完工程＝含稅發包工程費預算／契約金額＋有效管理費＋包工費以外－未完工程進項稅額，欄後標示 (未稅)。總額＝未完工程（未稅）＋該稅額。未提供稅額則未完工程與總額留空，不推定稅率。V0.8.0 原始費用以 historical_v080 保存供追溯。
3. 手動儲存立即提交，先提交目前表格編輯器內容、不等60秒。已有寫入／其他操作則有序接續，不平行競爭寫入、不忽略要求；自動儲存維持輸入停止60秒。
4. Windows 標題列 _／─／□／×；_ 位於一般最小化左側、專供系統匣；─ 保留工具列最小化。匣不可用時 _ 改一般最小化並提示。關閉仍保留未儲存確認；可拖曳、雙擊最大化、邊緣縮放與右下尺寸握把。
5. 預算表工具列「刪除」針對選取修訂版：須解鎖與確認，可回復，不刪來源 Excel 或其他修訂版。
6. 發包工程／發包以外／管理費的清單、提撥分攤表：金額靠右；日期、期數、文字置中。金額編輯欄靠右。
7. 詳細表格式選擇自動／A3118／AB3155，表頭可指定或搜尋前100列；匯入預覽標示格式、工作表、表頭列、筆數與警告。A3118沿用16欄；AB3155九欄映射至共用16欄。未提供的欄留空，不把請示單號擅認為動支單號。來源前置資訊、原值、公式、快取、額外欄位與非項目列留存，不執行公式或外部連結。
